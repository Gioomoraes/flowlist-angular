# Flowlist

O Flowlist é um gerenciador de tarefas simples, feito com Angular, criado como um projeto prático para aprender o framework. Ele está em desenvolvimento e faz parte da minha jornada de estudos, então o código e o histórico de commits mostram como o projeto evolui passo a passo.

## Funcionalidades

- Adicionar uma tarefa digitando o título (Enter ou clique no botão de adicionar)
- Ver todas as tarefas em uma lista
- Marcar uma tarefa como concluída, ou desfazer
- Excluir uma tarefa
- Mensagem amigável quando não há tarefas
- Contador de tarefas concluídas (por exemplo, "1 de 3 feitas")

> As tarefas ficam apenas na memória, então são perdidas ao recarregar a página. Salvá-las é uma melhoria planejada.


## Objetivo de aprendizado

- Componentes standalone e como um componente liga sua classe, template e estilos
- Signals: `signal`, `computed`, e os recursos `input()` e `output()` baseados em signals
- Controle de fluxo nos templates: `@for` e `@if`
- Comunicação entre componentes (dados descem, eventos sobem) e por que cada tarefa precisa de um id único
- CSS com escopo de componente e variáveis CSS globais
- Fluxo de trabalho com Git, usando commits pequenos e descritivos
